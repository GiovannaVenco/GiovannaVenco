## 💻 Featured Project

### 🫶 Sistema de Gestão de Voluntários para ONGs

Sistema acadêmico em desenvolvimento, criado em **Python** para ajudar ONGs na organização de voluntários, habilidades, disponibilidades e atividades.

### O que já foi desenvolvido

- cadastro e listagem de habilidades;
- edição do nome das habilidades;
- ativação e inativação de habilidades;
- validação de campos vazios e nomes duplicados;
- geração automática de identificadores;
- menu interativo;
- organização inicial do código em arquivos separados.

### Próximas etapas

- cadastro de voluntários;
- cadastro de atividades;
- registro de disponibilidades;
- associação de habilidades;
- alocação automática de voluntários;
- persistência das informações.

### Regras planejadas para a alocação

O sistema deverá considerar:

- status do voluntário;
- disponibilidade de dia e horário;
- habilidades exigidas pela atividade;
- percentual de compatibilidade;
- quantidade de vagas disponíveis.
