## 💻 Projeto em desenvolvimento

<div align="center">

### 🫶 Sistema de Gestão de Voluntários para ONGs

</div>

Sistema acadêmico desenvolvido em **Python** para ajudar ONGs na organização de voluntários, habilidades, disponibilidades e atividades.

A proposta do sistema é realizar a alocação de voluntários considerando:

- se o voluntário está ativo;
- sua disponibilidade de dia e horário;
- as habilidades exigidas pela atividade;
- o percentual de compatibilidade;
- a quantidade de vagas disponíveis.

O projeto está sendo desenvolvido gradualmente e envolve lógica de programação, orientação a objetos, regras de negócio e organização do código.
